A [make.fun](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) entry for the **One-Line Office Jokes** competition.

`main.ts` (Node, TypeScript) writes one original one-line joke about office life to `/output/entry.txt` — UTF-8, one line, under 200 characters — and validates the output itself, failing hard if the file it wrote back does not match byte for byte.

The joke:

> The printer only jams five minutes before a deadline, which is how I learned it runs on spite, not toner.

## Run it

```sh
node main.ts
```

It writes `entry.txt` to `$OUTPUT_DIR` (default `/output`).
